# 義消隊務管理平台（Google Sheet CRUD API 版）

## 線上資料模式

本版本已包含 `google-apps-script/` 後端，可將前端資料改為 Google Sheet。

前端 `config.js`：

```javascript
USE_ONLINE_DATA: true,
API_BASE_URL: '你的 Google Apps Script Web App /exec 網址'
```

### API 權限

- Announcements：R
- Persons：R
- Duties：CRUD
- Training：R
- MemberRecords：R
- Awards：R
- TrainingRules：R
- AwardRules：R
- Certificates：R

### 部署步驟

1. 建立 Google Sheet，開啟「擴充功能 → Apps Script」。
2. 複製 `google-apps-script/Code.gs`、`Setup.gs`、`SampleData.gs`、`appsscript.json`。
3. 執行 `setupSheets()` 建立所有工作表與標頭。
4. 需要目前範例資料時執行 `seedSampleData(false)`；若要清除後重建則執行 `seedSampleData(true)`。
5. 部署為 Web App，執行身分選擇部署者，存取權限依內部環境設定。
6. 將 `/exec` 網址填入 `config.js`，並將 `USE_ONLINE_DATA` 改為 `true`。

詳細說明請見 `google-apps-script/README.md`。

# 義消隊務管理平台（前端範例）

## 資料來源切換
修改 `config.js`：

```javascript
USE_ONLINE_DATA: false // 範例 JSON + LocalStorage
USE_ONLINE_DATA: true  // Google Apps Script Web App
```

## 前端權限
- 公告：R
- Person：R
- Duty：CRUD
- Training：R
- MemberRecord：R
- Awards：R
- Statistics：R

## 定位規則
- 協勤：簽到、簽退皆需定位確認；定位資料不保存。
- 常年訓練出席：簽到需定位確認；定位資料不保存。
- 常年訓練請假：不需定位。
- 公差勤務：簽到、簽退皆不需定位。

## 時間規則
簽到／簽退時間固定使用 30 分鐘級距（00:00、00:30、01:00、01:30……）。

## 獎項與訓練資格
`training-rules.json` 已設定新進人員基本訓練與基礎幹部講習班期限；`award-rules.json` 已設定全國義消楷模服務滿 5 年條件。畫面提供法規連結；其他未納入系統的獎項只保存取得紀錄，不自動推估資格。

## 執行方式
因使用 JSON 檔案，請用本機 HTTP Server 開啟，不要直接雙擊 `index.html`。

## 權限與資料範圍

目前登入者由 `config.js` 的以下欄位模擬：

```javascript
CURRENT_USER_NATIONAL_ID: 'E123714468',
CURRENT_USER_NAME: '吳宇樺'
```

權限依 Person 主檔的 `department` 判斷：

- `分隊部`：可查看同一大隊、同一分隊的全部個人資料，並可進入隊務統計。
- 其他部門／個人：個人資料查詢固定為自己，不能切換其他人，也不能查看隊務統計。

範例切換：

- 分隊部：`E123714468 / 吳宇樺`
- 個人：`A223456789 / 陳怡君`

前端隱藏與頁面攔截只負責 UI 體驗。正式串接 Google Apps Script 後，後端 API 必須依登入者再次檢查權限與資料範圍，不能只相信前端傳入的身分證字號或姓名。

## 登入與權限

- 入口：`login.html`
- 使用者輸入身分證字號後，系統由 `Person` 人員主檔解析姓名、分隊與權限。
- 登入資訊保存在瀏覽器 `sessionStorage`，關閉分頁後需重新登入。
- 分隊部可查詢同分隊人員並查看隊務統計；個人只能查看自己且不能進入隊務統計。

## 定位允許地點

定位半徑在 `config.js` 的 `GEOLOCATION_ALLOWED_RADIUS_METERS` 設定，預設 300 公尺。

- 日月光K11：22.72221409885418, 120.30464711481426
- 吉林街：22.644364761041626, 120.30651999999968
- 新興分隊：22.6309519358328, 120.31120251097644

## Console 記錄

`config.js`：

```javascript
ENABLE_DEBUG_LOG: true
```

會輸出登入、權限、資料讀取、勤務表單、定位判斷、CRUD、個人履歷及統計初始化的重要資訊。

## 定位資料保存原則
定位僅在新增勤務打卡時確認是否位於允許範圍。系統不將經緯度、精度、地點名稱、距離或定位時間寫入 Duty 資料。修改既有勤務時不重新要求定位。

## 勤務簽到與簽退流程

- 使用者先選擇勤務類型並完成簽到。
- 協勤與公差勤務會建立「尚未簽退」紀錄，簽退日期與時間保持空白。
- 使用者下次進入出勤紀錄頁面時，從「進行中勤務」按鈕完成簽退。
- 協勤簽到與簽退都需通過允許地點定位驗證，但不保存任何定位資料。
- 公差勤務簽到與簽退不需定位。
- 常年訓練出席只辦理簽到；常年訓練請假不需要簽到或簽退，第一次儲存即完成。
- 同一位人員同一時間只允許存在一筆尚未簽退的勤務。
